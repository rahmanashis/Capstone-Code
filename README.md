## 🌟 About The Project

This repository contains the source code for a unique capstone project developed throughout the semester as part of a course module. The project was built entirely from scratch in C programming under the rigorous guidance of our faculty.

**Project Description:** 
This project aims to provide a robust, unified solution for managing student data, employee records, and library operations within a centralized, terminal-based architecture. It was a journey of applying core programming concepts, memory management, and advanced problem-solving skills to bring a creative, product-engineering mindset to life.
